# Meeting Copilot v0.1.9 — no usage statistics

The macOS Capture application no longer contains product-usage reporting:

- Removed the Setup switch and Advanced statistics setting.
- Removed the tracking identifier, event queue, HTTP sender and event hooks.
- Removed the usage-statistics CLI command.
- Installer migration removes the retired setting and identity/queue files,
  preserving other settings, recordings and transcripts.

Recording, local transcription, recovery and optional external AI/delivery
remain available. Removing usage reporting does not disable services selected
by the user or promise that all product features are offline.

This remains an unsigned technical beta, not a notarized production release.
Automatic updates remain disabled.

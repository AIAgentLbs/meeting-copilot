# MeetOnTrack 0.1.11

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- AI tool, model, effort and speed are chosen per task: live analysis and chat,
  live translation, screenshot relevance, summary rewrite, meeting summary and
  speaker names. Options are discovered from the AI tools installed and signed
  in on this Mac (Codex, Claude Code, local Ollama) and from what your plan
  offers. Nothing is hardcoded or preselected. Antigravity is detected but not
  yet selectable, because it cannot be held to read-only, no-tools calls.
- After updating, open Getting started and choose a tool and model for each
  task, then run the check. Until a task has a choice, its AI step is skipped
  with a clear message. Recording and local transcription work without AI.
- Native summaries and speaker names now use the same chosen AI and the shared
  settings file; a legacy "no summary backend" setting migrates once to
  summaries off.
- Fixed: an old "Install Codex" error saved with a meeting no longer reappears
  after restart once the AI setup has been repaired.

Speech-to-text engine selection is unchanged in this release. Cloud AI receives
the selected text context of the task it runs. Google/SMTP integrations remain
optional and off for new installations. No usage-statistics feature is included.

## Update

Finish the call and quit Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

The installer verifies the pinned package checksum and preserves recordings and
settings. Automatic installation is deferred; version notifications are enabled
by default and can be disabled in Settings.

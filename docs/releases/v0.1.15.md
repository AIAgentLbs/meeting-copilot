# MeetOnTrack 0.1.15

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- Zoom speaker names are matched phrase by phrase. When several people speak
  in turn, each phrase gets the name of the person whose tile was highlighted
  while they spoke, not one name for the whole stretch. The package now
  includes the image libraries this needs; without them speakers stayed
  unnamed.
- The report delivery button says what is wrong and what to do: "Report for
  'Weekly sync' on October 16 was not sent" with one Send again button, "may
  not have arrived" when it is unknown, or "Email: sign in again" leading
  straight to Settings. Failures that were already fixed no longer show.
- A damaged report status file repairs itself. If the report file itself is
  gone, the button offers to create the report again.
- A cleaner main screen: the interface language moved to Settings, the helper
  lines under the buttons are gone, and the live transcript can be hidden and
  shown again. These choices are remembered.
- Speech models count their languages correctly in English and Russian, and a
  one-language model names its language.

Everything from 0.1.14 is included.

Cloud AI receives the selected text context of the task it runs. Cloud speech
recognition receives the audio only when you choose a cloud engine.
Google/SMTP integrations remain optional and off for new installations. No
usage-statistics feature is included.

## Update

Finish the call and quit Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 and later show
this update in the app.

The installer verifies the pinned package checksum and preserves recordings and
settings. Automatic installation is deferred; version notifications are enabled
by default and can be disabled in Settings.

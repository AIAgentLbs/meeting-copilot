# MeetOnTrack 0.1.12

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- Choose the AI once. In Getting started, pick the tool, model, effort and
  speed one time, and every AI task uses that choice: live analysis and chat,
  live translation, screenshot relevance, summary rewrite, meeting summary and
  speaker names. If 0.1.11 had the same choice for every task, it is kept. A
  task the chosen model cannot do, for example screenshots with a model that
  does not accept images, is shown as unavailable with the reason, and the
  other tasks keep working.
- One speech recognition choice. Getting started has one speech card for the
  engine, the model and the language. The same model writes the live and the
  final transcript. The options come from what this Mac and your accounts
  offer, each model shows its download size, and nothing is preselected.
- If the installer already downloaded exactly one speech model, MeetOnTrack
  uses it with no question. With several models or none, choose one in
  Getting started.
- A Parakeet model that is already on this Mac, also one downloaded by another
  app such as FluidVoice, is reused instead of downloaded again. The other
  app's files are not changed.
- Speakers are separated live and again after the call. The speaker model is
  downloaded together with the local speech models. If it cannot be
  downloaded, transcripts still work and show the two sides of the call.
- Call audio is now labelled "Others" ("Остальные" in Russian). Your own
  microphone stays "You".
- A recording made before the speech choice is ready waits for it. No
  transcription attempt is used up, and the recording is transcribed as soon
  as the choice is ready.
- Fixed: live translations of a finished meeting are kept when the service
  restarts. The installer no longer stops with "Bootstrap failed: 5:
  Input/output error" when it restarts the service during an update.

Cloud AI receives the selected text context of the task it runs. Cloud speech
recognition receives the audio only when you choose a cloud engine.
Google/SMTP integrations remain optional and off for new installations. No
usage-statistics feature is included.

## Update

Finish the call and quit Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Version 0.1.12 checks the new
address, so later versions are announced in the app again.

The installer verifies the pinned package checksum and preserves recordings and
settings. Automatic installation is deferred; version notifications are enabled
by default and can be disabled in Settings.

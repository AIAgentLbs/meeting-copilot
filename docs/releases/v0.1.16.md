# MeetOnTrack 0.1.16

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- Fact check on the main screen. During a call, statements that can be checked
  appear in a strip with the name of the person who said them: green
  "Confirmed", yellow "Neither confirmed nor refuted", or red "Refuted" with
  the source and what is actually true. The check uses the AI you chose in
  Getting started. It checks on the web only when that AI can search the web;
  otherwise it checks your connected knowledge base and says which AI would
  add web checks. Finished checks also appear in the meeting report.
- A call followed right away by another now gets its final transcript and its
  report. Before, the finished call kept only its live text and could be left
  without a report.
- The library explains a sound dropout in plain words instead of "Recording
  needs attention", for example: "The other side's audio was lost from 14:02
  to 14:05: their words in that stretch may be missing." A stretch in which
  the other side's words were still recognized from the saved recording no
  longer counts as a dropout.
- On the first start after the update, older meetings are brought up to date.
  Meetings that ended within the last 3 days get their reports sent
  automatically through the delivery you set up. Older meetings get a saved
  report with a Send button, so nothing old is sent without you.

Everything from 0.1.15 is included.

Cloud AI receives the selected text context of the task it runs. Fact checking
sends the checked statement and matching knowledge base excerpts to the AI you
chose. Cloud speech recognition receives the audio only when you choose a cloud
engine. Google/SMTP integrations remain optional and off for new installations.
No usage-statistics feature is included.

## Update

Finish the call and quit Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 and later show
this update in the app.

The installer verifies the pinned package checksum and preserves recordings and
settings. Automatic installation is deferred; version notifications are enabled
by default and can be disabled in Settings.

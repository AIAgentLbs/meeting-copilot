# MeetOnTrack 0.1.10

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- MeetOnTrack identity and M icon throughout native setup, Dock and menu bar.
- First-run language selection, clearer recording/model setup and optional AI.
- Meeting library, timed notes, meaningful questions and a separate meeting
  boundary during a continuous recording, with confirmation.
- Connected local folders without Git; optional read-only Google context.
- Optional report delivery: SMTP or a user's own Google OAuth JSON, independent
  email/Drive consent, visible status and explicit retry controls.
- New-version notification, release notes and a copyable update command.
- Retained recording recovery and reduced repeated background reads/work.

The Mac package includes native Capture, Python 3.12.13, web UI and compiled
helpers. No Python, Swift compiler or Apple SDK is required on the user's Mac.
Codex is optional for AI answers; capture and local transcription work without it.
Google Chrome is needed for PDF export. Cloud AI receives the selected text
context. Google/SMTP integrations are optional and off for new installations.
No usage-statistics feature is included.

## Update

Finish the call and quit Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

The installer verifies the pinned package checksum and preserves recordings and
settings. Automatic installation is deferred; version notifications are enabled
by default and can be disabled in Settings.

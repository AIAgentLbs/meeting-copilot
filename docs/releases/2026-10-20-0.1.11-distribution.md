## Explicit limits

No physical Windows host and no clean Mac were used: real microphone,
system-audio, headphone/reconnect, permission and installed tray acceptance
are not claimed. Mac is ad-hoc signed and not notarized; Windows is unsigned.
No real AI provider call (Codex, Claude Code, Ollama) was made by these release
checks, by rule; provider discovery and calls are covered by unit tests with
fakes. Users must choose a tool and model per task after updating; until then
AI steps report that a choice is needed. Speech-to-text engine selection is
unchanged (phase 3 of `docs/specs/2026-10-20-no-hardcoded-models.md`).
The live website still serves its own 0.1.10 installer snapshots and links
until the website repository is updated; this release did not change it.
No automatic installer is enabled. Never restart an active recording to update.

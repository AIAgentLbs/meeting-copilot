# MeetOnTrack 0.1.13

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- When a speech model is already downloaded, MeetOnTrack picks it for you.
  With several downloaded models it takes the newest one. You can still change
  the choice in Getting started.
- The live transcript starts in the middle of a call as soon as speech
  recognition becomes available. You no longer have to start a new recording.
- A red banner shows anything that blocks recording, the transcript or AI,
  with a button that fixes it or opens the right setting. When everything
  works, there is no banner.
- Error messages are plain language instead of technical text.
- "Start new meeting" works whenever audio is recording.
- Call audio recovers by itself within about 20 seconds when the capture of
  the other side goes quiet.
- Removed: the All/Me/Others filter, "Analyse now", the automatic analysis
  checkbox and the Questions/Risks/Decisions tabs.

Cloud AI receives the selected text context of the task it runs. Cloud speech
recognition receives the audio only when you choose a cloud engine.
Google/SMTP integrations remain optional and off for new installations. No
usage-statistics feature is included.

## Update

Finish the call and quit Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Version 0.1.12 shows this update
in the app.

The installer verifies the pinned package checksum and preserves recordings and
settings. Automatic installation is deferred; version notifications are enabled
by default and can be disabled in Settings.

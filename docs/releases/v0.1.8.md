# Meeting Copilot v0.1.8 — technical beta

Apple Silicon, macOS 15 or newer. Includes a freshly compiled Swift Capture
application and the matching web service; this is not a web-only patch over
an older recorder. Python 3.10+, Apple Command Line Tools and an authenticated
Codex CLI are still required by the one-command installer.

## Included

- Reduced repeated JSON parsing and annotation work; bounded translation work,
  cross-meeting caches and Copilot chat retention. Recording markers gate
  report preparation before expensive history scans.
- Simultaneous question/risk registers, panel swapping, repository call
  preparations and durable checklist status.
- Recovery health distinguishes audio capture from recognition. Recognition
  recovery preserves the existing active recording; short automatic dictations
  do not become archived meetings. First-launch interface language selection.
- Separate meeting-chat capture/import, conservative screenshot relevance,
  meaningful-question filtering and canonical manual speaker corrections.
- Optional Google Calendar/Gmail/Drive context through gws. One account;
  explicit settings and per-source opt-in. Drive provides metadata/links,
  not full document ingestion. External delivery remains optional.
- Quiet in-app delivery health and retry handling, without recurring messages
  saying that everything is healthy.

## Limits

This is an ad-hoc-signed, non-notarized technical beta, not a Developer ID
commercial distribution. Automatic Sparkle updates remain disabled; finish
the call, quit Capture and rerun the version-pinned installer to update.
Never disable Gatekeeper globally to install it.

Eight synthetic meetings, existing web regressions and local restart recovery
have been checked. Multi-hour/40-hour real-call memory soak, growing screenshot
history, clean-device audio permissions and all reconnection scenarios remain
acceptance gates. Temporary AI/image-analysis helpers can still consume much
more memory than the idle web service. See [memory audit](../memory-performance.md).
Fully offline AI analysis and selectable local model downloads remain planned.

Recordings and private settings are not included in the release package.
The installer preserves user data, backs up the previous app/web files and
refuses to replace a running Capture instance.

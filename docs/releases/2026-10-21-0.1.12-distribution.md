## Existing installations

0.1.9, 0.1.10 and 0.1.11 do not learn about 0.1.12 in the app; there is no
automatic installation in any version. Those users must run the installer
command once (website or release notes). From 0.1.12 on, notices work again.

## Owner Mac update

The owner's Mac (0.1.11, `effb7a2`) was updated the normal way: Capture quit
(no call active), then the pinned `install.sh` from `fabefac` ran and reported
"v0.1.12 installed; existing recordings and private settings were preserved".
Afterwards `GET /api/updates` reports 0.1.12 (technical-beta, `84d5aaa`, no
newer release); `GET /api/ai` and `GET /api/stt` answer 200, the AI choice is
ready. `config.json` kept its exact key set (18 keys) and bytes. Speech:
`needs_choice`, not adopted. `stt-options` lists two downloaded local models,
`parakeet-tdt-0.6b-v3-coreml` and Nemotron multilingual 1120 ms; with more than
one candidate the spec keeps `needs_choice`, so the owner chooses once in
Getting started.

## Explicit limits

No physical Windows host and no clean Mac were used: real microphone,
system-audio, headphone/reconnect, permission and installed tray acceptance are
not claimed. Mac is ad-hoc signed and not notarized; Windows is unsigned. No
real AI provider or cloud speech call was made by these release checks, by
rule. The speech recognition choice is Mac-only; Windows waits for
MEETONTRACK-69. The live website still serves its own installer snapshots and
links until the website repository is updated; this release did not change it.
No automatic installer is enabled. Never restart an active recording to update.

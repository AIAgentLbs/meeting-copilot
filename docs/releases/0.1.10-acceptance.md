# MeetOnTrack handoff candidate — 2026-10-19

Status: candidate, **not an accepted public release**. Both Apple Silicon Mac
and Windows are required. A successful source test is not a successful clean
installation or an audio-device acceptance test.

## Feedback coverage

- First-run native setup now focuses on permissions and local/live model readiness;
  optional provider and storage choices remain in Settings. Existing compatible
  models are reused. Final and streaming models are explained separately.
- Setup completion and the alternate action open the web assistant. The recorder
  and menu expose an explicit assistant action instead of relying on discovery
  of a crowded menu bar. Mac location labels use plain language.
- The web first-run panel explains recording, optional Codex access, and context.
  Its example is explicitly illustrative, not a fabricated real answer.
- A user-triggered AI check sends only a synthetic READY request to GPT-6.1 Sol.
  Installed CLI, authentication, quota and successful inference are distinct.
  Missing CLI/account access does not prevent the recorder or transcript UI.
- Start failures stay visible through status polling on Mac and clear after a
  successful start. Windows already guards duplicate in-flight Start operations.
- Explicit folder connections work without Git or uploads. Current supported
  local formats are UTF-8 text, Markdown, CSV and source code. Disconnect resets
  subsequent AI context; already sent excerpts cannot be recalled from providers.
- Opt-in Google sources remain separate. The first two eligible Drive results can
  include Docs text or the first Sheets tab's A1:Z80. Other results are explicitly
  metadata-only. This is **not** full Excel/PDF/Office support.
- Source UI is MeetOnTrack, with the AI Agent Labs link retained. Native icons are
  generated from the waveform brand, not the upstream feather. Required upstream
  license notices and internal compatibility identifiers are intentionally kept.
- Mac helper executables are compiled and signed at packaging time. The installer
  does not require the user to compile Swift or authenticate Codex before recording.
- A clean relocatable CPython 3.12.13 runtime is included in the Mac payload. The
  launcher and LaunchAgent use this private runtime, not the system Python.

## Handoff blockers and remaining acceptance

- Windows test machine is offline in Tailscale. Verify installation of the exact
  packaged bytes through the website installer when the machine is available.
  A managed CI artifact alone does not include the native ASR runtime bundle.
- Test both platforms with real, consented two-sided speech; repeated Start,
  silence, stop/resume, headphone reconnect and device switching. Do not infer
  hardware acceptance from source tests or one previously successful call.
- Local Excel/PDF/Office documents need bounded extractors and packaging. Google
  Sheets snippets are not a substitute. Network-mounted folder cancellation is
  cooperative, not a strict wall-clock guarantee.
- Google setup still requires a configured OAuth client. Verify new-account
  connection, source permissions and a real bounded retrieval before promising
  one-click Google onboarding. No real Google account was read in this UI test.
- Verify the embedded runtime on a clean Mac. Native signing/notarization remains
  outstanding; never advise disabling platform security protections.
- Provide a short end-to-end demo and verify the website's direct download route.
  Do not silently replace the public installer pin with an untested candidate.

## Reproduction

Run `python3 -m unittest scripts.test_installer scripts.test_release_branding` and
`node scripts/test-context-sources-ui.cjs`. Run web tests with Pillow and NumPy
available: `python3 -m unittest discover -s copilot/web -p 'test_*.py'`.
`scripts/preview-first-run.py --port 43990` uses disposable state without workers,
real transcripts or credentials. Stop it with Ctrl-C after browser acceptance.
Run Swift tests from `capture/`; the documented SDK workaround may be required
on a Command Line Tools-only Mac. See the repository's existing build guidance.

For packaging, download a clean standalone runtime into a disposable directory
using `uv python install --no-config --no-bin --no-registry --install-dir <dir>
cpython-3.12.13-macos-aarch64-none`; set `MEETING_COPILOT_PYTHON_RUNTIME` to that
distribution directory. Its licenses are included unchanged. Do not package a
developer's site-packages or an existing virtual environment. Run
`python3 scripts/check_macos_candidate.py <archive>` to verify the exact manifest,
fresh/repeat installation and relocated server import without launching Capture.
